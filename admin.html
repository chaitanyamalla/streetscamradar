Checking whether you are an admin…

There is no “add member” button, and there cannot be one. Creating an account needs Supabase’s admin API and the secret key, and that key bypasses every rule protecting this database — so it can never be in a page served to the public. Anyone can sign up on the map themselves; what you do here is decide what they are once they have.

The first admin is made in the Supabase SQL editor, which is the only place it can be done: update public.profiles set role = 'admin' where id = (select id from auth.users where email = 'you@example.com');

Approving a report clears its flags, so the same people cannot re-hide what you have already looked at. Hiding keeps it in the table; deleting does not, and is for a report that should never have been filed at all.

The points each rung needs. Level 1 is where everybody starts, so it stays at 0, and each rung has to ask for more than the one below it — the database refuses a ladder that does not climb. Names come from the site’s nine translation files, so a rung past level 10 shows as a bare number until one is added there.

Close a whole region rather than listing countries one at a time — the single-country box below is for the odd exception.

Numbers that change how the site behaves, applied the moment they are saved. Every one of them is read as a number somewhere, so a word here is refused rather than failing quietly at the next refresh.
